# Portfolio Report — Power BI + SharePoint Sales Analytics

## Purpose
Demonstrate a documented cloud-file-to-Power-BI workflow for sales pipeline reporting.

## Recommended report sections
- Pipeline overview: opportunities, open amount, won amount proxy, win rate.
- Stage distribution: opportunity count and amount by stage.
- Performance cuts: lead source, segment, region, sales representative.
- Data and refresh checks: duplicate IDs, date types, authentication, refresh status.

## Interpretation guardrails
All records are synthetic and opportunity amounts are not accounting revenue. This repository contains starter assets, not a native Power BI report, live Microsoft 365 connection, scheduled refresh, or deployed Power Apps application. Only claim cloud refresh after testing it in your tenant.

## Suggested action
Build the native report from the provided workbook/CSV, validate measures and slicers, and capture screenshots after testing.
